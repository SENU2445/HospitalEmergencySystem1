# Mini Hospital Emergency Management System

## Course
CIT300 - Data Structures and Algorithms

## Assignment
Individual Mid Assignment

## Description
This project is a Mini Hospital Emergency Management System developed in Java using different data structures.

## Data Structures Used
- Binary Search Tree (BST) - Patient Records
- Queue - Emergency Patient Queue
- Stack - Treatment History
- Singly Linked List - Patient Visit History

## Features
- Add Patient
- Search Patient
- Delete Patient
- Display Patients
- Add Patient to Emergency Queue
- Treat Next Patient
- Display Waiting Patients
- Add Treatment Record
- Display Treatment History
- Add Patient Visit
- Search Patient Visit
- Remove Patient Visit
- Display Patient Visit History

## Technologies
- Java
- NetBeans
- GitHub
